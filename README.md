A dense one-page newspaper summing up Tuesday 17 November 2026 in a single
image: a serif masthead with date and index ear boxes, a "By the Numbers"
strip, 13 featured stories with datelines (Kerch Bridge, Bahrain/Qeshm, the
Manila Quad summit, Nvidia, Ebola, COP31, Gaza, measles, Mongolia, Serbia,
Bangladesh, the An-12 crash, Mondlane's trial), a world map with numbered
pins 1-13, and 30 more verified stories in three region-grouped digest
columns — 43 stories, six continents, every one of them from that one
Tuesday. The entry program copies the finished front page to the output
directory and verifies the copy byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
